Mục 2.4.1 · Flowchart kiểm chứng từ implementation

KAgent – Quy trình hoạt động của hệ thống

Luồng của một yêu cầu thông thường trong giao diện terminal. Sơ đồ chỉ thể hiện các bước nằm trên execution path: từ khởi tạo CLI/TUI, tiếp nhận prompt, chuẩn bị context, đến vòng lặp LLM–tool và phản hồi cuối.

Bảng kiểm chứng với mã nguồn

Phạm vi sơ đồ: normal prompt trên terminal UI. Các slash command và cú pháp #/#! được nhận diện trước vòng Agent; chúng là nhánh riêng, không mặc định đi qua LLM. MCP, Burp bridge và các tool/plugin chỉ xuất hiện nếu được cấu hình hoặc bật.
Flow step Source file Class / Function Vai trò Evidence
Entry point src/cli/main.py cli_main() → main() Điểm vào console script kagent. pyproject.toml khai báo kagent = src.cli.main:cli_main; cli_main gọi asyncio.run(main()).
Bootstrap src/cli/main.py main() Nạp config, LLM client, skills, target, stores, tool registry; khởi tạo Agent và TUI. Agent(opts) và KAgent(AppProps(...)); MCP tools chỉ register sau discover_mcp_tools().
Input routing src/ui/core/app.py KAgent.submit() Phân loại text input. #/#! gọi agent.add_memory(); / gọi handle_slash(); còn lại tạo task run_agent_turn().
Agent run src/ui/core/app.py, src/agent/agent.py run_agent_turn() → Agent.run() → run_inner() Thiết lập abort/event handling và chạy một lượt agent. Agent.run() luôn phát event done ở finally; UI chuyển event thành transcript state.
Context preparation src/agent/agent.py run_inner() Reconcile history, mở rộng file mention, thêm guidance/planner, intelligence và memory recall vào working. build_decision_plan(), build_intelligence_context(), recall_curated_memory() được chèn trước user message trong working context.
Persistence / compaction src/agent/agent.py, src/session/store.py auto_compact(), compact_in_place(), Store.save() Lưu history/target/session memory; nén khi token estimate chạm ngưỡng. Ngưỡng gồm history + incoming input + tool schemas. Nén dùng LLM, merge SessionMemory, save JSON và context snapshot Markdown.
LLM interaction src/agent/agent.py, src/llm/openai.py, src/llm/retry.py Agent.chat(), Client.chat[_stream](), with_retry() Gửi messages/tool specs đến provider và nhận assistant message/tool calls. OpenAI-compatible client POST tới /chat/completions; lỗi transient được retry tối đa 2 lần theo RetryOptions.
Decision / termination src/agent/agent.py run_inner() Quyết định dựa trên resp.message.tool_calls. Nếu không có tool call: emit text (nếu cần) rồi return. Nếu hết max_steps: emit MaxStepsError; UI hỏi Continue/Stop.
Tool dispatch src/agent/agent.py, src/tools/registry.py execute_tool_calls(), run_parsed_tool_call(), Registry.execute() Parse/validate call, lookup tool, kiểm tra allow-list skill và permission, sau đó gọi tool.run(). Stateful load_skill chạy tuần tự; call độc lập có thể chạy song song, giới hạn 4.
Tool result feedback src/agent/agent.py record_tool_result() Đưa kết quả về context để LLM quyết định tiếp. Tạo Message(role="tool", content=result, tool_call_id=...), append vào history/working và save. Exception thành ERROR: ....

Nguồn kiểm chứng: mã nguồn trong workspace KAgent, trace theo đường gọi normal prompt. Sơ đồ không giả định database, cache hay HTTP API nội bộ; persistence thực tế trên path này là session JSON/context snapshot và các file store cục bộ khi tính năng tương ứng được dùng.
